A *vertex colouring* of a graph $G = (V, E)$ with colour set $C$ is a function $f:V \to C$ such that $f^{-1}(c)$ is an independent set for all $c \in C$. The *chromatic number* $\chi(G)$ of $G$ is the cardinality of the smallest colour set for which there exists a vertex colouring of $G$. If $G$ admits a vertex colouring with $k$ colours, then $G$ is called *$k$-colourable* or $k$*-partite*.
